# 같은 소식 묶기

## 한 줄 소개
여러 매체가 같은 소식을 보도하면 카드 하나로 묶고 "같은 소식 · 외 N개 매체"로 보여 줍니다.

## 왜 만들었나요
같은 사건 기사가 여러 장 반복되면 화면이 길어지고 중요한 다른 기사가 묻힙니다.

## 어떻게 쓰나요
1. 묶인 카드에는 **같은 소식 · 외 N개 매체**가 보입니다.
2. 누르면 다른 매체의 제목과 링크가 펼쳐집니다.
3. 카테고리 오른쪽 위 건수에 "(같은 소식 묶음 · 기사 N건)"으로 원래 기사 수도 함께 나옵니다.

## 어떻게 동작하나요
1. 기사 제목에서 문장부호를 빼고 두 글자씩 잘라 조각을 만듭니다. (예: "캐논메디칼" → 캐논, 논메, 메디, 디칼)
2. 두 제목의 조각이 얼마나 겹치는지 0~1 사이 점수로 계산합니다.
3. 점수가 0.45 이상이고 날짜 차이가 3일 이내면 같은 소식으로 묶습니다.
4. 정렬 순서에서 가장 먼저 나온 기사가 대표 카드가 됩니다.

## 설정 방법
묶는 기준을 바꾸려면 `static/articles.js`의 `SAME_NEWS_LEVEL` 값을 고칩니다.
- 숫자를 올리면 (예: 0.55) 더 비슷해야 묶입니다.
- 숫자를 내리면 (예: 0.35) 더 많이 묶입니다.

## 알아두면 좋은 점
- 제목 글자로만 판단하므로 완벽하지 않습니다. 제목이 많이 다른 같은 소식은 안 묶이고, 같은 학회의 "개막"과 "성료" 기사처럼 비슷한 제목의 다른 소식이 묶일 수 있습니다.
- 같은 카테고리 안에서만 묶습니다.
- 화면에서만 묶습니다. CSV에는 기사가 모두 따로 들어갑니다.

## 관련 파일
- `static/articles.js` (`titlePieces`, `similarity`, `groupSameNews`)
