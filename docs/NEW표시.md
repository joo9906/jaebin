# NEW 표시

## 한 줄 소개
지난번에 사이트를 본 뒤로 새로 들어온 기사에 빨간 "NEW" 표시를 붙여 줍니다.

## 왜 만들었나요
매일 들어올 때 어떤 기사가 새로 들어왔는지 찾기 어려웠습니다. 새 기사만 바로 볼 수 있게 했습니다.

## 어떻게 쓰나요
1. 사이트에 들어오면 제목 아래에 "지난 방문 이후 새 기사 N건"이 보입니다.
2. 새 기사 카드 왼쪽 위에 **NEW**가 붙습니다.
3. **NEW만 보기**를 체크하면 새 기사만 남습니다.

## 어떻게 동작하나요
1. 기사마다 "서버에 저장된 시각"이 있습니다.
2. 사이트를 볼 때 가장 최근 저장 시각을 브라우저에 기억해 둡니다.
3. 다음에 들어오면, 기억해 둔 시각보다 나중에 저장된 기사에 NEW를 붙입니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 처음 방문할 때는 비교할 기록이 없어서 NEW가 붙지 않습니다.
- 기억은 브라우저(컴퓨터·크롬/엣지별)에 저장됩니다. 다른 PC나 시크릿 창에서는 따로 계산됩니다.
- 새로고침만 해도 "본 것"으로 처리되어, 다음 새로고침부터는 NEW가 사라집니다.

## 관련 파일
- `static/articles.js` (`isNew`, `rememberLastSeen`)
- `app/service.py` (기사의 `saved_at` 전달)
