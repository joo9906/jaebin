# 아침 브리핑 자동 전송

## 한 줄 소개
하루 예약 수집이 끝나면 카테고리별 주요 기사를 Slack 또는 Teams 대화방에 자동으로 보냅니다.

## 왜 만들었나요
사이트에 들어오지 않아도 아침에 주요 기사를 메신저로 받아 볼 수 있게 하려고 만들었습니다.

## 어떻게 쓰나요
1. Slack(또는 Teams)에서 "웹훅 주소(메시지를 받는 주소)"를 만듭니다.
2. `.env` 파일에 `BRIEFING_WEBHOOK_URL=주소`를 적습니다.
3. 서버를 다시 시작합니다. 예약 수집(`AUTO_ENABLED=true`)이 켜져 있어야 합니다.

## 어떻게 동작하나요
1. 예약 수집이 목록 확인과 본문 확인을 모두 끝내고 "처리할 작업 없음"이 되거나, 하루 처리 상한에 도달하면
2. 어제~오늘 기사 중 (메인 키워드만 맞은 기사와 숨긴 기사는 빼고) 카테고리마다 3건씩 뽑아 제목·출처·링크를 글로 만들고
3. 웹훅 주소로 보냅니다.
4. 보낸 날짜를 기록해서 하루에 한 번만 보냅니다.

## 설정 방법
`.env`
```
BRIEFING_WEBHOOK_URL=https://hooks.slack.com/services/...
```
비워 두면 브리핑은 보내지 않습니다.

## 알아두면 좋은 점
- 전송은 하루 한 번만 시도합니다. 실패하면 서버 기록(로그)에만 남고, 그날은 다시 보내지 않습니다. (1분마다 실패를 반복하지 않게 하려는 것)
- 화면의 "예약 작업 1회 시험"으로도 마지막 단계에 도달하면 브리핑이 나갈 수 있습니다.
- 메일 전송은 아직 없습니다.
- Teams는 사용하는 웹훅 종류에 따라 글 형식이 맞지 않을 수 있어, 실제 주소로 한 번 시험해 보세요.
