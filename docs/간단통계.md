# 간단 통계

## 한 줄 소개
카테고리별 기사 수, 경쟁사별 언급 횟수, 최근 14일 날짜별 기사 수를 막대그래프로 보여 줍니다.

## 왜 만들었나요
기사 수를 눈으로 한 번에 보고, 어느 경쟁사 소식이 많은지 발표 자료로 바로 쓰기 위해 만들었습니다.

## 어떻게 쓰나요
1. 화면 위쪽 카테고리 바로가기 아래의 "간단 통계" 영역을 봅니다.
2. 검색·분야·기간·⭐ 필터를 바꾸면 통계도 같이 바뀝니다.

## 어떻게 동작하나요
1. 화면이 받아 둔 기사 목록에서 필터를 통과한 기사만 셉니다.
2. 카테고리별 개수와, 경쟁사 카테고리 기사의 회사 이름별 개수를 셉니다. (많은 순 최대 8개)
3. 최근 14일(한국 시간) 날짜마다 기사 수를 세어 세로 막대로 그립니다. 막대에 마우스를 올리면 날짜와 건수가 보입니다.
4. 가장 큰 값을 100%로 놓고 HTML/CSS 막대로 그립니다. 별도 그래프 도구는 쓰지 않습니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 최근 200건 기사 안에서 센 값입니다.
- 서버 저장 없이 화면에서 매번 계산합니다.
- 숨긴 기사는 세지 않습니다. ("숨긴 기사 보기"를 켜면 포함)
- 기사가 아주 많으면(200건 초과) 오래된 날짜의 막대가 실제보다 낮게 보일 수 있습니다.
