# 오래된 기사 정리

## 한 줄 소개
발행한 지 90일이 지난 기사를 자동으로 "보관함"으로 옮겨 화면에서 빼 줍니다. ⭐나 메모가 있는 기사는 그대로 둡니다.

## 왜 만들었나요
기사가 계속 쌓이기만 하면 화면이 길어지고 느려집니다. 지금 볼 필요가 없는 옛날 기사를 치우기 위해 만들었습니다.

## 어떻게 쓰나요
따로 누를 것은 없습니다. 기사를 수집할 때마다 자동으로 정리됩니다.
- 오래된 기사를 계속 남기고 싶다면 ⭐를 누르거나 메모를 달아 두세요.

## 어떻게 동작하나요
1. 정보원에서 기사 목록을 수집할 때마다 정리를 한 번 합니다.
2. 발행일이 90일보다 오래된 기사를 찾습니다.
3. 그중 ⭐도 없고 메모도 없는 기사를 "보관함" 상태로 바꿉니다.
4. 보관함 기사는 화면, CSV, 브리핑, 통계, 주간 리포트에 나오지 않습니다.
5. 지우는 것이 아니라 상태만 바꾸는 것이라, 기사 자료는 DB(기사 저장소)에 그대로 남아 있습니다.

## 설정 방법
`wrangler.toml` 파일에서 날짜 수를 바꿀 수 있습니다. (7~3650일, 범위를 벗어나면 90일)
```
ARCHIVE_DAYS = "90"
```
바꾼 뒤에는 `npm run deploy`로 다시 올려야 반영됩니다.

## 알아두면 좋은 점
- 아직 화면에서 보관함을 열어 보는 기능은 없습니다. 자료는 `data/news.db`에 남아 있습니다.
- 보관된 뒤에 ⭐를 붙여도 화면에 다시 나오지 않습니다. 남기고 싶은 기사는 90일이 되기 전에 표시해 두세요.
- 숨긴 기사도 오래되면 똑같이 보관함으로 옮겨집니다.

## 관련 파일

- `wrangler.toml` (`ARCHIVE_DAYS`)
