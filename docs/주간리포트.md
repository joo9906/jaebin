# 주간 리포트

## 한 줄 소개
버튼 한 번으로 GPT가 최근 7일 기사를 읽고 주간 회의용 리포트 초안을 써 줍니다.

## 왜 만들었나요
매주 기사를 다시 훑어보며 동향을 정리하는 시간을 줄이기 위해 만들었습니다.

## 어떻게 쓰나요
1. 화면 아래쪽 **주간 리포트** 영역에서 **주간 리포트 만들기**를 누릅니다.
2. 잠시 기다리면 (최대 2분 정도) 리포트가 나옵니다.
3. **복사하기**를 눌러 메일이나 문서에 붙여 넣습니다.
4. 리포트에 넣고 싶은 기사가 있으면 미리 ⭐로 표시해 두세요.

## 어떻게 동작하나요
1. 서버가 최근 7일(오늘 포함) 기사를 고릅니다. 숨긴 기사와 메인 키워드만 맞은 기사는 뺍니다.
2. ⭐ 표시한 기사가 하나라도 있으면 ⭐ 기사만 씁니다. 없으면 전체를 씁니다. (최대 30건)
3. 기사 제목, 매체, AI 요약을 GPT에 보내고 정해진 형식으로 리포트를 받습니다.
   - 이번 주 동향 5줄
   - 경쟁사 움직임
   - 다음 주에 지켜볼 점
4. 받은 글을 화면에 보여 줍니다. (저장은 하지 않음)

## 설정 방법
AI 요약과 같은 OpenAI 키를 씁니다. `.env`에 아래가 있으면 됩니다.
```
OPENAI_API_KEY=sk-...
```

## 알아두면 좋은 점
- 누를 때마다 GPT 비용이 조금 듭니다. (기사 30건 기준 한 번에 수십 원 수준)
- GPT가 쓴 초안이므로 회의 전에 내용을 꼭 확인하세요.
- 키가 없거나 인터넷이 안 되면 "리포트를 만들지 못했습니다" 안내가 나옵니다.
- 리포트 형식은 `app/ai_summary.py`의 `WEEKLY_PROMPT` 문구를 고치면 바뀝니다.

## 관련 파일
- `static/report.js` (버튼·복사)
- `app/main.py` (`/api/weekly-report`), `app/service.py` (`make_weekly_report`), `app/ai_summary.py` (`weekly_report`)
