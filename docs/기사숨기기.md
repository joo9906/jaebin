# 기사 숨기기

## 한 줄 소개
잘못 분류됐거나 필요 없는 기사를 카드의 "숨기기" 버튼으로 목록에서 치울 수 있습니다.

## 왜 만들었나요
키워드로 자동 분류하다 보니 관계없는 기사가 섞일 때가 있습니다. 매번 보고 넘기지 않도록 치워 두는 기능입니다.

## 어떻게 쓰나요
1. 기사 카드 오른쪽 아래 **숨기기**를 누르면 카드가 사라집니다.
2. 다시 보고 싶으면 위쪽 **숨긴 기사 보기**를 체크합니다. 숨긴 기사가 흐리게 점선 카드로 보입니다.
3. 흐린 카드의 **다시 보이기**를 누르면 원래대로 돌아옵니다.

## 어떻게 동작하나요
1. 숨기기를 누르면 서버의 기사 저장소에 "숨김" 상태로 기록합니다. (삭제가 아니라 표시만 바꿈)
2. 화면은 숨김 상태인 기사를 기본으로 빼고 보여 줍니다.
3. 같은 기사가 나중에 다시 수집되어도 숨김 상태는 그대로 유지됩니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 숨긴 기사는 통계, CSV 다운로드, 아침 브리핑, 주간 리포트에서도 빠집니다.
- 모든 사용자에게 똑같이 숨겨집니다. (사람별 구분 없음)

## 관련 파일
- `static/articles.js` (숨기기 버튼, 숨긴 기사 보기)
- `app/main.py` (`/api/article-hide`), `app/service.py` (`set_hidden`, `visible_articles`)
