# CSV 내보내기

## 한 줄 소개
화면의 "기사 다운로드(CSV)" 버튼을 누르면 모아 둔 기사 목록이 엑셀 파일로 내려받아집니다.

## 왜 만들었나요
보고서나 주간 회의 자료에 기사 목록을 붙여 넣을 때, 하나하나 복사하지 않아도 되게 하려고 만들었습니다.

## 어떻게 쓰나요
1. 화면 위쪽 검색창 줄에서 **기사 다운로드(CSV)** 버튼을 누릅니다.
2. `smd-news.csv` 파일이 내려받아집니다.
3. 엑셀로 열면 한글이 깨지지 않고 보입니다.

## 어떻게 동작하나요
1. 버튼을 누르면 서버에 기사 목록을 요청합니다.
2. 서버가 저장된 기사(최대 200건)를 표 형태의 글자 파일로 만듭니다.
3. 발행일, 카테고리, 회사·기관, 출처, 제목, AI 요약, 첫 문단, 키워드, 중요 표시, 메모, 원문 링크가 한 줄에 하나씩 들어갑니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 화면에서 건 필터(검색·기간 등)와 상관없이 저장된 기사 전체가 내려받아집니다.
- AI 요약은 OpenAI 키를 넣어 두었을 때만 채워집니다.
- 엑셀이 `-`, `=`, `+`, `@`로 시작하는 칸을 수식으로 잘못 읽지 않도록, AI 요약의 `- `는 `• `로 바꾸고, 다른 칸은 맨 앞에 `'`를 붙입니다.
- 메인 키워드만 맞은 기사도 함께 들어갑니다.
- 숨긴 기사는 들어가지 않습니다.
