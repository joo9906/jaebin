# 화면 편의 기능 (기간 필터 · 정렬 · 중요 표시 · 메모)

## 한 줄 소개
기사를 기간별로 걸러 보고, 순서를 바꾸고, 중요한 기사에 ⭐와 짧은 메모를 남길 수 있습니다.

## 왜 만들었나요
기사가 쌓이면 오늘 기사나 중요한 기사를 찾기 어렵습니다. 자주 쓰는 조작을 화면에서 바로 할 수 있게 했습니다.

## 어떻게 쓰나요
1. **기간**: "전체 기간 / 오늘 / 최근 7일" 중에서 고릅니다.
2. **정렬**: "최신순 / 오래된순 / ⭐ 먼저" 중에서 고릅니다.
3. **⭐만 보기**: 체크하면 중요 표시한 기사만 남습니다.
4. **중요 표시**: 기사 카드 오른쪽 위의 ☆를 누르면 ★로 바뀌고 저장됩니다. 다시 누르면 해제됩니다.
5. **메모**: 카드 아래 "메모 달기"를 누르고 글을 쓴 뒤 **저장**을 누릅니다. (300자까지)

## 어떻게 동작하나요
- 기간 필터와 정렬은 화면에 이미 받아 둔 기사 목록을 브라우저가 다시 골라 보여 줍니다. 서버는 쓰지 않습니다.
- ⭐와 메모는 누르는 순간 서버에 보내 DB(기사 저장소)에 저장합니다. 새로고침해도 남아 있습니다.
- 기사가 다시 수집되어 갱신돼도 ⭐와 메모는 지워지지 않습니다.

## 설정 방법
따로 설정할 것 없음

## 알아두면 좋은 점
- 기간은 한국 시간 기준 기사 발행일로 계산합니다.
- 메모와 ⭐는 서버를 쓰는 모든 사람에게 똑같이 보입니다. (사람별 구분 없음)
- 예전에 만든 DB에는 서버를 켤 때 자동으로 칸이 추가됩니다.

- `app/main.py` (`/api/article-star`, `/api/article-memo`)
- `app/service.py`, `app/db.py` (저장)
