# 기능 문서 목록

> 전체 기능을 한눈에 보려면 [기능 모음집](기능모음집.md)을 먼저 보세요.

- [AI 인사이트](AI인사이트.md) — GPT가 기사마다 영상의학 장비 회사 입장의 기회/위협·인사이트·대응할 일 작성 (예전 AI 요약), 🟢기회/🔴위협 표시와 필터
- [CSV 내보내기](CSV내보내기.md) — 기사 목록을 엑셀 파일로 내려받기
- [화면 편의 기능](화면편의기능.md) — 신문 브리핑형 목록, 검색(검색어 강조), 기간 필터, 정렬, ⭐ 중요 표시, 메모
- [간단 통계](간단통계.md) — 카테고리별·경쟁사별·날짜별 막대그래프
- [아침 브리핑](아침브리핑.md) — 수집이 끝나면 Slack/Teams로 주요 기사 전송
- [기사 숨기기](기사숨기기.md) — 필요 없는 기사를 목록에서 치우고 되돌리기
- [NEW 표시](NEW표시.md) — 지난 방문 이후 새로 들어온 기사 표시
- [같은 소식 묶기](같은소식묶기.md) — 여러 매체의 같은 소식을 카드 하나로 묶기
- [주간·월간 리포트](주간월간리포트.md) — GPT가 최근 7일/30일 기사로 회의 리포트 초안 작성
- [오래된 기사 정리](오래된기사정리.md) — 90일 지난 기사를 자동으로 보관함으로 옮기기
- [Cloudflare 배포](Cloudflare배포.md) — 자바스크립트(Cloudflare Worker)로 바꿔서 PC 없이 사이트·예약 수집 운영
- [빙 뉴스 검색](빙뉴스검색.md) — 키 없이 빙 뉴스에서 캐논메디칼·경쟁사·특수의료장비 검색어로 일반 언론 기사까지 모으기
- [정보원 상태](정보원상태.md) — 매체별로 수집이 잘 되는지, 며칠째 새 기사가 없는지 표로 보기
