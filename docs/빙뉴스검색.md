# 빙 뉴스 검색으로 기사 더 모으기

## 한 줄 소개
등록된 의료 전문 매체 말고도, 마이크로소프트의 뉴스 검색 서비스인 빙(Bing) 뉴스에서 "캐논메디칼", "GE헬스케어" 같은 검색어로 일반 언론 기사까지 모아 옵니다.

## 왜 만들었나요
- 지금까지는 등록한 매체 24곳의 기사 목록만 보았습니다. 그래서 경제지·일간지에 실린 경쟁사 기사는 놓쳤습니다.
- 네이버 뉴스 검색 API는 개발자 센터에서 키를 발급받아야 해서 번거롭습니다.
- 빙 뉴스 검색은 키 발급 없이 RSS(기사 목록을 정해진 형식으로 적은 글)를 줍니다. 원문 주소, 날짜, 기사 앞부분 1~2문장, 매체 이름까지 들어 있습니다.
- 구글 뉴스도 시험해 봤습니다. 하지만 원문 주소가 구글 전용 암호 주소로 감싸져 있고 기사 앞부분 문장도 주지 않아서 빙을 골랐습니다.

## 어떻게 쓰나요
1. 따로 할 일은 없습니다. 예약 수집이 매일 아침 다른 정보원과 함께 빙 검색 6개도 확인합니다.
2. 빙에서 온 기사는 출처가 **"매체 이름 (빙 검색)"**으로 보입니다. (예: "파이낸셜뉴스 (빙 검색)")
3. 바로 시험해 보고 싶으면 **⚙️ 수집 관리** 탭에서 정보원으로 **빙 검색 · ○○**를 골라 수집합니다.
4. 같은 탭의 **정보원 상태** 표에서 빙 검색이 잘 되는지 볼 수 있습니다.

## 어떻게 동작하나요
1. 검색어마다 빙 뉴스 검색 결과를 최신순으로 받아 옵니다. (한 번에 10건 안팎)
2. 7일보다 오래된 기사는 뺍니다.
3. 기존 매체와 똑같이, 기사 제목이 키워드 규칙(`src/config.json`)에 맞는 기사만 남깁니다.
   - 예: "필립스" 검색 결과에 섞여 온 "코노코필립스(석유회사)" 기사는 제외어로 걸러집니다.
4. 이미 다른 매체 정보원이 찾아 둔 기사(주소가 같은 기사)는 그 매체 쪽 기록을 그대로 둡니다.
5. 원문 페이지는 따로 읽지 않습니다. 빙이 준 기사 앞부분 1~2문장을 첫 문단으로 쓰고, 이것으로 AI 인사이트를 만듭니다.

## 설정 방법
검색어는 `src/config.json`의 정보원 목록에 B001~B006으로 들어 있습니다.

| 번호 | 검색어 |
|---|---|
| B001 | 캐논메디칼 |
| B002 | 지멘스 헬시니어스 |
| B003 | GE헬스케어 |
| B004 | 필립스 헬스케어 |
| B005 | 후지필름 헬스케어 |
| B006 | 특수의료장비 |

- 검색어를 바꾸려면 해당 정보원의 `listingUrl` 안 `q=` 뒤의 검색어를 바꿉니다. (한글은 주소용 글자로 바뀌어 있으니, 새로 만들 때는 빙 검색창 주소를 복사해 쓰면 편합니다)
- 예약 수집이 확인하는 정보원 수는 `wrangler.toml`에서 정합니다.
```
AUTO_SOURCE_LIMIT = "30"
```
  30이 최대라서, 지금(기존 24곳 + 빙 6개)이 꽉 찬 상태입니다. 빙 검색어를 더 늘리려면 다른 정보원을 빼야 합니다.
- 설정을 바꾼 뒤에는 `npm run deploy`로 다시 올려야 반영됩니다.

## 알아두면 좋은 점
- 빙 뉴스 RSS는 공식 API(정식으로 약속된 연결 창구)가 아닙니다. 빙이 형식을 바꾸거나 막으면 수집이 멈출 수 있습니다. 그럴 때는 **정보원 상태** 표에 실패로 나옵니다.
- **"OR" 검색은 안 됩니다.** (예: "후지필름 OR 유나이티드 이미징"은 결과 0건) 검색어 하나당 정보원 하나로 넣어야 합니다.
- 기사 앞부분 1~2문장만 보고 AI 인사이트를 쓰므로, 전문 매체 기사보다 인사이트가 짧을 수 있습니다.
- 같은 소식을 전문 매체와 빙이 서로 다른 주소로 가져오면 두 건이 됩니다. 화면의 **같은 소식 묶기**가 한 줄로 묶어 줍니다.
- 최근 7일 동안 검색어에 맞는 기사가 없으면 0건이 정상입니다. (예: 캐논메디칼 기사가 없는 주)
- MSN처럼 기사를 옮겨 실은 사이트의 주소가 들어올 때도 있습니다.

## 관련 파일
- `src/crawler.js` (`parseBingRss`: 빙 RSS 읽기, `fetchPage`: XML 형식 허용)
- `src/service.js` (`collectSource`: 앞부분 문장·날짜 미리 저장, `readBody`: 매체 이름 표시)
- `src/config.json` (B001~B006 정보원, `auto_order`), `wrangler.toml` (`AUTO_SOURCE_LIMIT`)
